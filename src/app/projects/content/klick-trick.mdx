Klick Trick is a bilingual website for a Moroccan digital marketing agency. The site introduces the agency, explains its services, and gives prospective clients clear routes to request a quote or start a conversation.

**Role:** Website development / AI-assisted implementation

## Project overview

The website supports French and English visitors through dedicated language routes. Each version keeps the same structure and calls to action while adapting navigation, service descriptions, and supporting content for its audience.

## Service architecture

The content organizes the agency's offer into six focused areas: digital marketing, branding and creative, web and technology, social media, AI and automation, and strategy and analytics.

Rather than presenting these as isolated capabilities, the site connects them through a shared process covering discovery, strategy, execution, and optimization. The homepage also provides dedicated paths to the full services, about, and contact pages.

## Design and user experience

The visual direction uses a dark interface, large editorial typography, restrained blue imagery, and high-contrast calls to action. The hierarchy moves from the agency proposition into services, working principles, process, audiences, and contact.

Navigation includes a direct language switcher and consistent access to the quote form. Descriptive text alternatives support the principal visual composition, while clear headings and skip navigation help structure the experience.

## Next.js implementation

The site is built with Next.js and deployed on Vercel. Locale-based routes provide separate French and English experiences, and the shared page structure keeps both versions consistent as the content changes between languages.

The implementation was developed with Claude as an AI-assisted coding tool. I directed the structure, content requirements, visual decisions, and review process while using the tool to support implementation.

## Current status

Klick Trick is live with its bilingual marketing experience, service pages, agency information, and contact flow. The project image shows the French homepage used for this case study.
